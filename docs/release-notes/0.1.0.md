## 🛠️ Novas Funcionalidades e Mudanças
Esta é a primeira release de fundação estrutural do ecossistema do **Comanda**. O objetivo principal foi conceber a fundação da infraestrutura, governança técnica, qualidade de código empresarial e fluxos arquiteturais de segurança.

### 🐳 1. Ambiente Dockerizado de Produção
* Implementação do arquivo orquestrador `docker-compose.yml` dividindo as cargas entre containers isolados de PHP 8.4-fpm (`comanda-app`), PHP do licenciador (`comanda-manager-app`), Nginx (`comanda-nginx`), banco de dados (`comanda-mysql`) e cache/filas (`comanda-redis`).
* Criação de configurações específicas do Nginx desativando expressamente o buffering de fastcgi para suporte de streams de realtime instantâneos via SSE.

### 📦 2. Arquitetura Modular e Isolamento
* Definição e mapeamento dos subdiretórios em estrita conformidade com o padrão arquitetural MVC Clássico + Services + DTOs + Value Objects.
* Criação do arquivo de configuração oficial `modules.php` em `www/config` mapeando todas as funcionalidades licenciáveis do produto.
* **Isolamento de Banco do Manager:** A aplicação do licenciador (`manager`) opera em base de dados dedicada (`comanda_manager`), mantendo total separação física do banco principal da aplicação (`comanda`).

### 🔑 3. Mecanismo de Licenciamento Criptográfico Local
* Desenvolvimento do fluxo de validação offline-first de licenças utilizando criptografia de chaves assimétricas RSA-2048.
* Implementação dos serviços `LicenseValidator`, `LicenseManager` e `ModuleAccessService` na aplicação principal para garantir a governança e proteção de acesso comercial dos módulos instalados.

### 📡 4. Tempo Real SSE & Healthchecks
* Estabelecimento do barramento funcional de Server-Sent Events (SSE) através do `SsePublisher` e do `SseEventFactory` com tratamento nativo de heartbeat de 15 segundos para monitoramento da conexão.
* Criação dos endpoints reais de saúde em `/health` no `www` e no `manager`, fornecendo telemetria em tempo real do banco de dados, Redis e licença ativa.

## 🛡️ Etapa de Hardening da Fundação (Concluída)
Realizamos uma consolidação rigorosa de segurança e qualidade estática antes de prosseguir à Fase 2:

* **Testes PHPUnit 12 Resolvidos:** Correção e porte de todas as anotações depreciadas (`@test`) para os atributos nativos do PHP 8+ (`#[Test]`). 100% dos testes unitários e de feature passando sem erros.
* **Qualidade Estática com PHPStan:** Integração do analisador estático PHPStan configurado no nível de segurança **5** com **0 erros** de tipo em toda a aplicação.
* **Frontend Base Totalmente Local:** Configuração profissional do `package.json` integrando TypeScript, Bootstrap 5 local, DataTables.net local e jQuery compilados fisicamente pelo Vite. **Zero CDNs ou conexões externas utilizadas.**
* **Typecheck, Build e npm audit Impecáveis:** Validação estrita de tipos com `npm run typecheck`, compilação rápida via `npm run build` e varredura física do `npm audit` retornando zero vulnerabilidades de segurança.
* **Validação OpenAPI Perfeita:** Validação estrita da especificação `openapi.yaml` utilizando a ferramenta real do Redocly, atingindo conformidade perfeita de rotas, esquemas de segurança bearer JWT e documentação.
